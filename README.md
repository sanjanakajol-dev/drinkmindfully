# Drink Mindfully

A lifestyle app that makes drinking less feel stylish: fast logging, streaks and shareable progress cards, with a premium guide to alcohol-free drinks and venues.

- Product spec: [docs/SPEC.md](docs/SPEC.md)
- Build plan: [docs/PLAN.md](docs/PLAN.md)
- Try it / connect the backend: [docs/SETUP.md](docs/SETUP.md)

Built with Expo (iOS, Android and web from one codebase) and Supabase (EU region).
